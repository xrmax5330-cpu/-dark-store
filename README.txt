DARK STORE - نسخة أولية جاهزة للنشر

الملفات:
- index.html = الموقع كامل
- assets/logo.jpeg = صورة الشعار التي أرسلتها

قبل النشر:
1) افتح index.html وابحث عن YOUR_WHATSAPP_NUMBER.
2) استبدله برقم واتساب بصيغة دولية بدون + أو مسافات، مثال ليبيا: 2189XXXXXXXX.
3) عدّل الأسعار أو المنتجات إذا احتجت.

الموقع متجاوب مع الجوال والكمبيوتر، ويحتوي على:
- واجهة Dark
- الشعار
- منتجات Robux
- نموذج طلب
- تحويل الطلب إلى واتساب
- قسم مميزات
- تذييل وحقوق
